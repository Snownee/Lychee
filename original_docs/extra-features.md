# Extra Features

## YAML recipes

You can now write any type of recipe in YAML format. All you need to do is to put the the file with `.yaml` extension in the `data/<namespace>/recipe` folder.

## `lychee:lightning_immune`

This entity-type tag is used to make entity immune to lightning damage and to prevent them from starting fires when struck by lightning.

## `lychee:lightning_fire_immune`

This entity-type tag is used to prevent entity from starting fires when struck by lightning.

## `lychee:fire_immune`

This item tag is used to prevent item from being destroyed by fire or lava.

## `lychee:dispenser_placement`

This item tag is used to allow item to be placed by dispensers.

## `lychee:extend_box`

This block tag can be applied to the landing block in block crushing recipes, allowing items inside the landing block to be processed as well. (e.g., cauldron)

## `lychee:skip_item_exploding`

This entity-type tag can be applied to an entity that can trigger explosions so that they won't trigger item exploding recipes and thereby reducing lag.

## `lychee:skip_block_exploding`

This entity-type tag can be applied to an entity that can trigger explosions so that they won't trigger block exploding recipes and thereby reducing lag.
