# Extra Features

## YAML recipes

You can now write any type of recipe in YAML format. All you need to do is to put the the file with `.yaml` extension in the `data/<namespace>/recipes` folder.

## `lychee:lightning_immune`

This entity-type tag is used to make entity immune to lightning damage and to prevent them from starting fires when struck by lightning.

## `lychee:lightning_fire_immune`

This entity-type tag is used to prevent entity from starting fires when struck by lightning.

## `lychee:fire_immune`

This item tag is used to prevent item from being destroyed by fire or lava.

## `lychee:dispenser_placement`

This item tag is used to allow item to be placed by dispensers.
